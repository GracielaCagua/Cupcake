# Cupcake App

Aplicación móvil desarrollada en **Android Studio** utilizando **Jetpack Compose**, basada en loscodelab oficiales de Android Developers.

Esta app implementa un flujo completo de pedidos de pastelitos (cupcakes), permitiendo gestionar cantidades, sabores, fechas de entrega y la compartición de los detalles del resumen del pedido.

---

## Tecnologías y Requisitos

* **Lenguaje:** Kotlin
* **UI Toolkit:** Jetpack Compose
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **IDE:** Android Studio (Electric Eel o superior recomendado)[cite: 1, 2]
